# Конфигурация отображения валюты

## 📁 Расположение файла
```
config/currency_display.json
```

Файл создаётся автоматически при первом запуске приложения.

## 🎯 Назначение

Система позволяет гибко настраивать отображение валюты в разных частях приложения:
- Символ валюты (Br, BYN, ₽, $, €)
- Позиция символа (до/после числа)
- Формат числа (разделители, знаки после запятой)
- Цвета для положительных/отрицательных значений

## 📋 Структура конфигурации

### Глобальные настройки

```json
{
  "defaultCurrency": "BYR",
  "globalSettings": {
    "symbol": "Br",
    "position": "After",
    "format": "Standard",
    "thousandSeparator": " ",
    "decimalSeparator": ".",
    "decimalPlaces": 2
  }
}
```

### Группы мест

Конфигурация разделена на **группы** по функциональным областям:

| Группа | Описание |
|--------|----------|
| `Reservations` | Бронирования |
| `Rooms` | Номера |
| `Clients` | Клиенты |
| `Expenses` | Дополнительные расходы |
| `Transactions` | Финансовые операции |
| `Reports` | Отчёты |
| `Settings` | Настройки |
| `General` | Общее |

### Пример настройки для расходов

```json
{
  "Expenses": {
    "defaultSettings": {
      "symbol": "Br",
      "position": "After",
      "format": "Standard"
    },
    "locationSettings": {
      "ExpensesTableAmount": {
        "symbol": "Br",
        "position": "After",
        "format": "Standard"
      },
      "ExpensesForm": {
        "symbol": "Br",
        "position": "Before"
      }
    }
  }
}
```

## 🔧 Параметры

### Символ валюты
- `symbol` — строка (например, "Br", "BYN", "$", "€")

### Позиция символа
- `Before` — перед числом (`Br 100.00`)
- `After` — после числа (`100.00 Br`)
- `Space` — без пробела (`100.00Br`)
- `None` — без символа (`100.00`)

### Формат числа
- `Standard` — `100.00` (с двумя знаками после запятой)
- `NoDecimals` — `100` (без дробной части)
- `Comma` — `100,00` (запятая как разделитель)
- `Grouped` — `100 00` (пробел как разделитель тысяч)

### Разделители
- `thousandSeparator` — символ для тысяч (пробел, запятая, точка)
- `decimalSeparator` — символ для дробной части (точка, запятая)
- `decimalPlaces` — количество знаков после запятой (0-4)

### Цвета
- `useColorForNegative` — использовать цвет для отрицательных значений
- `negativeColor` — цвет в формате HEX (`#EF4444`)
- `useColorForPositive` — использовать цвет для положительных значений
- `positiveColor` — цвет в формате HEX (`#10B981`)

## 📍 Конкретные места (CurrencyDisplayLocation)

### Бронирования
- `ReservationsTableAmount` — сумма в таблице
- `ReservationsColumnHeader` — заголовок колонки
- `ReservationsCard` — карточка бронирования
- `ReservationsForm` — форма создания/редактирования

### Расходы
- `ExpensesTableAmount` — сумма в таблице
- `ExpensesColumnHeader` — заголовок колонки
- `ExpensesForm` — форма расхода

### Номера
- `RoomsTablePrice` — цена в таблице
- `RoomsColumnHeader` — заголовок колонки
- `RoomsCard` — карточка номера

### Отчёты
- `ReportsFinancial` — финансовый отчёт
- `ReportsCharts` — графики и диаграммы

## 💻 Использование в коде

### В XAML

```xml
<TextBlock Text="{Binding Amount, Converter={StaticResource CurrencyDisplayConverter}, ConverterParameter=ExpensesTableAmount}"/>
```

### В C#

```csharp
var configService = ServiceLocator.GetService<ICurrencyConfigService>();
string formatted = configService.FormatPrice(100.50m, CurrencyDisplayLocation.ExpensesTableAmount);
// Результат: "100.50 Br"
```

## 🔄 Приоритет настроек

1. **Индивидуальная настройка места** (`locationSettings`)
2. **Настройка группы** (`defaultSettings`)
3. **Глобальные настройки** (`globalSettings`)

Если для места нет индивидуальной настройки, берётся настройка группы. Если нет настройки группы — глобальные настройки.

## 📝 Примеры

### Пример 1: Таблица расходов с "Br" после числа
```json
{
  "Expenses": {
    "locationSettings": {
      "ExpensesTableAmount": {
        "symbol": "Br",
        "position": "After"
      }
    }
  }
}
```
Результат: `100.00 Br`

### Пример 2: Форма с "Br" перед числом
```json
{
  "Expenses": {
    "locationSettings": {
      "ExpensesForm": {
        "symbol": "Br",
        "position": "Before"
      }
    }
  }
}
```
Результат: `Br 100.00`

### Пример 3: Отчёты с цветом для отрицательных
```json
{
  "Reports": {
    "defaultSettings": {
      "useColorForNegative": true,
      "negativeColor": "#EF4444"
    }
  }
}
```
Результат: отрицательные значения красные

### Пример 4: Без знаков после запятой
```json
{
  "General": {
    "defaultSettings": {
      "decimalPlaces": 0,
      "format": "Standard"
    }
  }
}
```
Результат: `100 Br`

## 🛠️ Редактирование

Можно редактировать файл вручную в любом текстовом редакторе. Изменения применяются при следующем запуске приложения.

**Важно:** Файл автоматически создаётся при первом запуске, если его нет.

## 🔁 Сброс настроек

Для сброса к дефолтным настройкам:
1. Удалите файл `config/currency_display.json`
2. Перезапустите приложение — файл создастся заново с дефолтными значениями

Или программно:
```csharp
await configService.ResetToDefaultsAsync();
```
